SonarSource analyzers used from SonarQube

This JAR does not bundle sonar-java or sonar-python. It uses the analyzers
installed in SonarQube, through their public API only, and requires
(Plugin-RequirePlugins):

  sonar-java    (plugin key java)   ${sonar.java.minVersion} or newer
  sonar-python  (plugin key python) ${sonar.python.minVersion} or newer

Obtaining source

Extract the source JAR from META-INF/third-party/analyzer-sources/ in this JAR.
It is the unmodified sources classifier published on Maven Central for
sonar-go-plugin ${sonar.go.version}. It can also be fetched from
https://repo.maven.apache.org/maven2/ using the Maven coordinate above.

The Go plugin source JAR omits the native Go-to-Slang bridge and shaded modules.
The complete release tree is additionally included in the same directory as
sonar-go-${sonar.go.version}-${sonar.go.source.revision}-source.zip.
It includes the native bridge, generated-source inputs, GoConverter and the
build scripts. The public commit's GitOrigin-RevId matches Implementation-Build
in the original plugin JAR; its published Java sources match the source JAR.
Original legal notices remain within the complete release archive.

Packaging

sonar-go is combined with this plugin using the Maven Shade plugin with
minimizeJar enabled: classes this plugin does not use are left out. The packages
org.sonar.go, org.sonar.plugins.go and org.sonarsource.analyzer.commons are
relocated to com.ibm.shaded.org.sonar.go, com.ibm.shaded.org.sonar.plugins.go
and com.ibm.shaded.org.sonarsource.analyzer.commons, so that they do not clash
with the sonar-go plugin installed in SonarQube. No other change is made.
Analyzer source archives and the namespaced legal files are copied without
change. The build configuration is distribution/plugin-with-go/pom.xml and
distribution/pom.xml in the matching Sonar Cryptography Plugin release at
https://github.com/cbomkit/sonar-cryptography.
