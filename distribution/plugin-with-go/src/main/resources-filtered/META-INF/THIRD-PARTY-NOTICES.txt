SonarSource analyzers used from SonarQube

installed in SonarQube, through their public API only, and requires
(Plugin-RequirePlugins):

Obtaining source

The sources are not included in this JAR. The unmodified sources JAR published
on Maven Central for sonar-go-plugin ${sonar.go.version} can be downloaded from
the "Sources JAR" URL above.

The Go plugin sources JAR omits the native Go-to-Slang bridge and shaded
modules. The complete release tree, including the native bridge,
generated-source inputs, GoConverter and the build scripts, can be downloaded
from the "Complete release source" URL above. The public commit's
GitOrigin-RevId matches Implementation-Build in the original plugin JAR; its
published Java sources match the sources JAR. Original legal notices remain
within the complete release archive.

The sources of the LGPL-3.0 modules can be downloaded from the URLs given with
them above.

Packaging

sonar-go is combined with this plugin using the Maven Shade plugin with
minimizeJar enabled: classes this plugin does not use are left out. The packages
org.sonar.go, org.sonar.plugins.go and org.sonarsource.analyzer.commons are
relocated to com.ibm.shaded.org.sonar.go, com.ibm.shaded.org.sonar.plugins.go
and com.ibm.shaded.org.sonarsource.analyzer.commons, so that they do not clash
with the sonar-go plugin installed in SonarQube. No other change is made.
The namespaced legal files are copied without change. The build configuration
is distribution/plugin-with-go/pom.xml and distribution/pom.xml in the matching
Sonar Cryptography Plugin release at
https://github.com/cbomkit/sonar-cryptography. To use a modified version of an
LGPL-3.0 module, rebuild sonar-go and then this plugin from that source with the
modified module.
