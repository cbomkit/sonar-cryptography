Corresponding source

The sources are not included in this JAR. The unmodified sources JAR of every
module listed above under "Bundled third-party components" can be downloaded
from Maven Central at the URL given with the module. The complete source of
each sonar-java, sonar-python, sonar-analyzer-commons and sslr release is
available from its release source tree.

Packaging

The modules above are combined with this library using the Maven Shade plugin.
The SonarSource modules are included whole and unmodified, with one exception:
their embedded copy of Jackson is left out. Jackson and CycloneDX core are not
bundled; they are Maven dependencies of this library. Package names are not
relocated.
The build configuration is distribution/library/pom.xml and
distribution/pom.xml in the matching release at
https://github.com/cbomkit/sonar-cryptography. To use a modified version of an
LGPL-3.0 component, rebuild the library from that source with the modified
component.
