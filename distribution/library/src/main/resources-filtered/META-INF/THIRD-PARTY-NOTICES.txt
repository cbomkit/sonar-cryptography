Corresponding source

The unmodified sources JAR of every module listed above under "Bundled
third-party components", as published on Maven Central, is included under
META-INF/third-party/analyzer-sources/. Each file is named
<module>-<version>-sources.jar. The same JARs are available from
https://repo.maven.apache.org/maven2/ under each module's Maven coordinate.

Packaging

The modules above are combined with this plugin using the Maven Shade plugin.
The SonarSource modules are included whole; of the other dependencies, classes
this plugin and the bundled modules do not use are left out (minimizeJar).
Package names are not relocated. The bundled components are not modified.
The build configuration is distribution/library/pom.xml and
distribution/pom.xml in the matching release at
https://github.com/cbomkit/sonar-cryptography. To use a modified version of an
LGPL-3.0 component, rebuild the library from that source with the modified
component.
