SonarSource analyzers

This JAR bundles no SonarSource analyzer. It uses the analyzers installed in
SonarQube, through their public API only, and requires (Plugin-RequirePlugins):

  sonar-java    (plugin key java)   ${sonar.java.minVersion} or newer
  sonar-python  (plugin key python) ${sonar.python.minVersion} or newer

It contains no Go support.

Packaging

This plugin is combined with its dependencies using the Maven Shade plugin with
minimizeJar enabled: unused classes are left out, and package names are not
relocated. The build configuration is distribution/plugin/pom.xml and
distribution/pom.xml in the matching release at
https://github.com/cbomkit/sonar-cryptography.
