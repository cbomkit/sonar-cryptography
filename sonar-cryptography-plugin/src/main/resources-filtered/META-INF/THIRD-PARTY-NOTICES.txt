Obtaining source

Extract the source JARs from META-INF/third-party/analyzer-sources/ in this JAR.
They are the unmodified sources classifiers published on Maven Central for the
resolved Java, Python and Go analyzer modules, including Java and Python
frontends, checks and other resolved modules in those Maven groups. Each
filename identifies the module and its exact version. They can also be fetched
from https://repo.maven.apache.org/maven2/ using each module's Maven coordinate.
Source-specific legal notices remain within each source JAR.

The Go plugin source JAR omits the native Go-to-Slang bridge and shaded modules.
The complete release tree is additionally included in the same directory as
sonar-go-${sonar.go.version}-${sonar.go.source.revision}-source.zip.
It includes the native bridge, generated-source inputs, GoConverter and the
build scripts. The public commit's GitOrigin-RevId matches Implementation-Build
in the original plugin JAR; its published Java sources match the source JAR.
Original legal notices remain within the complete release archive.

Packaging

Analyzer bytecode is combined with this plugin using Maven Shade with
minimizeJar enabled. Unused classes are removed; package names are not relocated.
Analyzer source archives and the namespaced legal files are copied without changes.
The build configuration is sonar-cryptography-plugin/pom.xml in the matching
Sonar Cryptography Plugin release at https://github.com/cbomkit/sonar-cryptography.
